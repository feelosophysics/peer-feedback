# 동료평가 상호 피드백 초안 도우미

대면 동료평가 대화를 브라우저에서 받아적어, **평가자 → 피평가자**와 **피평가자 → 평가자** 피드백 초안 두 개를 만드는 로컬 웹 도구입니다. 초안은 실제 대화 내용을 충실하게 정리할 뿐 형식적인 칸(고마움·개선점 등)을 억지로 채우지 않고, 피드백 입력란(일반 텍스트, 2000자)에 바로 붙여넣을 수 있게 `- ` 목록과 빈 줄만 씁니다. 따로 나만 보는 **대화 돌아보기**에서 내 대화가 어땠는지(발언 비중, 질문 수, 미션 관련 이야기 비중 등)를 훑어볼 수 있습니다.

OpenAI 호환 게이트웨이(`/v1/models`, `/v1/chat/completions`)를 쓰며, 외부 패키지 없이 내 PC에서 실행합니다.

---

## 한눈에 보기

아래는 동작을 보이려고 지어낸 짧은 예시입니다(실제 출력은 대화 길이에 따라 400–900자 안팎).

- **입력**
  - 메모 한 줄: `캐시 미션 · 상대 이름 지우`
  - 체크 항목(선택): `만료 시점을 왜 그렇게 정했는지 묻기`
  - 대본: Chrome이 받아적은 대화 (화자 표시 없음)
- **출력 1 · 초안 (다정한 대화체)**
  ```text
  지우님, 오늘 캐시 이야기 정말 재밌었어요.

  캐시를 언제 비울지
  - 읽을 때 만료를 확인하신 이유를 들으면서 고개가 끄덕여졌어요.
  - “틀린 값을 빨리 주는 것보다 느려도 맞는 값이 낫다”는 말이 기억에 남아요.
  ```
- **출력 2 · 대화 돌아보기 (나만 보는 참고, 초안에 들어가지 않음)**
  - 발언 비중 막대: 평가자 35% · 피평가자 60% · 불명 5%
  - 질문 7번 · 주고받기 18번 · 가장 길게 이어진 설명: 피평가자 약 640자 (03:10–06:45)
  - 대화 성격 막대: 미션 관련 / 미션 밖 탐구 / 잡담
  - 시간 흐름 색 띠, 체크 항목별 `다룸` / `안 다룸`

## 쓰는 법

1. **메모 (선택):** 미션명, 또는 상대가 말한 미션 해석 한 줄. 상대 이름을 적으면 다정한 대화체 초안에서 이름을 불러 줍니다. 비워 두면 대화로 추론합니다.
2. **체크 항목 (선택):** 대화에서 다뤘는지 돌아보고 싶은 것을 한 줄에 하나씩. 비워 두면 무시합니다. 넣으면 대화 돌아보기에 항목별 `다룸` / `안 다룸`이 나옵니다.
3. **녹음 또는 대본 붙여넣기:** `● 녹음 시작`으로 받아적거나, 대본 칸에 대화 메모를 붙여넣고 `이 대본만으로 초안 생성`을 누릅니다.
   - 기본 모드(실시간 받아적기 전용)는 키 없이 녹음할 수 있습니다. 키는 초안을 만들 때만 필요합니다.
   - 초안 없이 받아적기만 하려면 `■ 녹음만 종료`를 누릅니다. 대본은 화면과 자동 백업에 남아서, `● 녹음 시작`으로 이어 녹음하거나 나중에 키를 넣고 `이 대본만으로 초안 생성`을 누를 수 있습니다.
4. **다듬기**
   - **말투:** 다정한 대화체(기본) · 정중한 해요체 · 담백한 개조식
   - **분량:** 짧게(약 300자) · 기본(대화 근거만큼, 약 400–900자) · 길게(2000자 이내 상세)
   - **대화 포인트:** 주제·종류(질문/설명/함께 해결/배운 점/개선/여담)·원문 인용·미션 관련도로 정리됩니다. 체크를 빼거나 직접 추가한 뒤 `선택 조건으로 다시 다듬기`를 누르면 고른 포인트만으로 초안을 다시 씁니다. 평가자와 피평가자가 반대로 잡혔으면 `⇄` 버튼으로 뒤집습니다.
   - 초안 아래 글자 수가 `/2000`을 넘으면 빨갛게 경고합니다. 혹시 남은 `**`, `#` 같은 기호는 자동으로 지웁니다.

### 대화 돌아보기 숫자는 어떻게 나오나

대본에는 화자 표시가 없어서, 모델이 대본 줄마다 **추정 화자 · 질문 여부 · 미션 관련도**만 붙이고 숫자는 브라우저가 셉니다(모델에게 비율을 직접 묻지 않음).

- 발언 비중·대화 성격: 공백을 뺀 글자 수 기준
- 주고받기: 화자가 바뀐 횟수
- 시간 흐름: 녹음 중 받아적은 줄마다 녹음 경과 시간(일시정지 제외)을 기록해 그립니다. 붙여넣은 대본처럼 시각 정보가 없으면 발언 순서(글자 수 비례)로 그립니다.

화자를 문맥으로 추정하므로 화면에 **문맥 추정 · 근사치**라고 표시합니다. 정확한 측정이 아니라 다음 평가를 준비하며 흐름을 훑어보는 용도입니다.

## 실행하기

설치할 패키지가 없습니다(설치 용량 0 MB, 실행 약 1초). Node.js 18 이상 또는 Python 3 중 하나가 필요합니다.

```powershell
cd peer-feedback
node server.mjs
```

macOS·Linux에서는 `python3 server.py`도 됩니다. 실행하면 `http://localhost:8765`가 열립니다. 실시간 받아적기(Web Speech API)는 일반 **Google Chrome**에서 가장 안정적입니다.

1. 초안을 만들려면 **1. 게이트웨이 연결 및 테스트**에 게이트웨이 주소와 OpenAI 호환 Virtual Key를 넣습니다(받아적기만 할 때는 건너뛰어도 됩니다). 주소는 `http://localhost:8765/#api=https://게이트웨이주소`로 북마크해 두면 자동으로 채워집니다.
2. `연결 테스트`로 로컬 프록시 · 키 권한 · 초안 생성을 확인합니다.
3. 녹음하거나 대본을 붙여넣어 초안을 만듭니다. 다 쓴 뒤 공용 PC라면 `저장된 키·주소 삭제`를 누르고 터미널에서 `Ctrl+C`로 종료합니다.

실행기 옵션: `--port <번호>`(기본 8765, 사용 중이면 8766–8775 자동 탐색) · `--no-open`(브라우저 자동 열기 끔) · `--allow-host <호스트>`(프록시 대상 제한)

## 음성 직접 전송 점검 (`tools/audio-probe.mjs`)

기본 모드는 **실시간 받아적기 전용**이라 게이트웨이에는 음성 대신 받아적은 대본만 보냅니다. 고급 설정에서 **게이트웨이 오디오 우선**을 고르면 녹음을 16kHz WAV로 게이트웨이에 보내는데, 게이트웨이가 음성을 조용히 버리고도 정상 응답(HTTP 200)을 줄 수 있습니다. 그래서 연결 테스트는 같은 문장을 **음성 없이 / 2초 신호음과 함께** 보내 `usage.prompt_tokens`가 늘었는지로 판정합니다(Gemini는 음성 1초를 약 32토큰으로 셉니다). 연결 테스트를 건너뛰고 바로 녹음해도, 첫 녹음을 보내기 전에 같은 점검을 한 번 합니다.

| 결과 | 뜻 |
|---|---|
| 음성 직접 분석 준비 완료 | 토큰이 음성 길이만큼 늘었다 |
| 음성이 모델까지 전달되지 않음 | 요청은 통과했지만 토큰이 거의 그대로다 → 받아적기로 자동 전환 |
| 판정 보류 | 게이트웨이가 토큰 사용량을 돌려주지 않는다 |

판정 보류이거나 더 확실히 보고 싶으면 터미널에서 점검 도구를 씁니다. 확인 문장을 읽은 음성(Windows 한국어 음성 또는 macOS `say`)을 보내 모델이 확인 단어를 받아적는지까지 봅니다. 키는 화면에 보이지 않게 입력받고 출력하지 않습니다.

```powershell
node tools/audio-probe.mjs --base https://게이트웨이주소 --model gemini-3-flash
```

`--audio 파일.wav`로 직접 녹음한 파일을 쓸 수도 있습니다.

## 개인정보와 보안

- **로컬 프록시:** `server.mjs` / `server.py`가 `127.0.0.1`에서 화면과 `/api/proxy/*` 요청만 중계합니다. 사설망·로컬 주소로의 요청은 막고, 터미널에 키와 본문을 남기지 않습니다.
- **받아적기:** 실시간 받아적기는 Chrome 음성 인식(Web Speech API)을 씁니다. Chrome은 인식을 위해 음성을 Google 서버로 보낼 수 있으므로, 이 도구가 게이트웨이로 음성을 보내지 않는 모드에서도 음성이 PC 밖으로 전혀 나가지 않는다고 보장하지는 않습니다.
- **즉시 파기:** 녹음 파일을 디스크에 저장하지 않습니다. 충돌 복구용 임시 버퍼(IndexedDB)와 대본 자동 백업은 초안을 만든 직후 지웁니다. `전체 즉시 파기`로 언제든 모두 지울 수 있습니다.

## 자주 겪는 문제

- **"로컬 실행기가 연결되지 않았습니다" 배너 / CORS 오류:** 파일을 직접(`file://`) 열지 말고 실행기로 `http://localhost:8765`를 엽니다.
- **받아적기가 기록되지 않음:** 일반 Google Chrome인지, 마이크 권한을 허용했는지 확인합니다. 대화 메모를 붙여넣어 `이 대본만으로 초안 생성`을 써도 됩니다.
- **브라우저를 닫아 버림:** 다시 열면 자동 백업된 대본(녹음 시각·체크 항목 포함)을 복구할지 묻습니다.
