# 동료평가 상호 피드백 초안 생성기

브라우저에서 동료평가 대화를 녹음해 **평가자·피평가자 화자를 구분한 핵심 대화 요약**과 **양쪽 피드백 초안**을 만들고, 분석이 끝나면 음성과 임시 버퍼를 즉시 파기하는 로컬 실행형 웹 도구입니다. OpenAI 호환 게이트웨이 API(`/v1/models`, `/v1/chat/completions`) 전용으로 동작합니다.

---

## 입력에서 출력까지 (사용 예시)

1. **입력:** 5–15분 분량의 대면 동료평가 대화를 브라우저 마이크로 녹음(또는 음성 파일 불러오기 · 대본 백업)하고 필요하면 미션명 메모 한 줄을 적습니다.
2. **출력 (3단 구성):**
   - **1단 · 화자별 핵심 대화 포인트:** 질문·검증(평가자), 구현 설명(피평가자), 강점, 개선 제안을 체크리스트로 정리합니다. 체크를 해제하거나 직접 항목을 추가해 다시 다듬을 수 있습니다.
   - **2단 · 평가자 → 피평가자용 피드백 초안:** 확인한 기능과 설계 이유(Why), 함께 해결한 문제, 구체적 근거 기반의 개선점을 담은 주 초안입니다.
   - **3단 · 피평가자 → 평가자용 피드백 초안:** 평가자의 질문·인사이트에 대한 감사 인사와 배운 점을 정리해 동료에게 공유할 수 있는 초안입니다.

---

## 동작 방식과 보안 원칙

1. **동일 출처 로컬 프록시 (`127.0.0.1`):**
   로컬 실행기(`server.mjs` 또는 `server.py`)가 `http://localhost:8765`에서 정적 화면과 `/api/proxy/*` 요청을 중계합니다. API 키와 대화 내용이 제3자 외부 서버를 거치지 않으며, 사설망·로컬·IP 기반 주소로의 SSRF 요청 및 경로 역추적 요청은 차단되고, 실행기 터미널에도 키와 본문을 기록하지 않습니다.
2. **Chrome 실시간 받아적기 기본 + 텍스트 연결 테스트 + 선택형 오디오 경로:**
   - 기본 모드는 **실시간 받아적기 전용(음성 외부 무전송)**입니다. **연결 테스트** 버튼이 로컬 프록시 연결 → `/v1/models` OpenAI 호환 키 검증 → 초경량 텍스트 초안 생성 및 JSON 모드 자동 우회 여부를 약 1–2초 안에 점검하고 버튼 아래 진단 박스에 결과를 표시합니다.
   - 일반 Google Chrome에서 녹음하면 실시간 한국어 받아적기(Web Speech API)가 기본으로 펼쳐진 대본 창에 바로 기록되며, 녹음 음성을 파일로 저장하거나 외부로 보내지 않습니다.
   - 추후 게이트웨이가 오디오 직접 입력을 지원하거나 음성 파일을 분석해야 할 때는 고급 설정에서 **게이트웨이 오디오 우선 (16kHz WAV)** 모드로 전환할 수 있으며, 이 경우에도 분석 직후 음성은 즉시 파기됩니다.
3. **즉시 파기:**
   로컬 디스크에 녹음 파일을 저장하지 않으며, 브라우저 충돌 복구용 임시 버퍼(IndexedDB)와 메모리(RAM)의 음성은 초안 생성 완료 직후 영구 삭제됩니다.

---

## 한계와 주의점

- **OpenAI 호환 Virtual Key 필요:** `/v1/chat/completions` 프로토콜을 지원하는 OpenAI 호환 Virtual Key를 입력해야 합니다. (OpenAI 호환 게이트웨이 위에서 `gemini-3-flash`, `gpt-5.4-mini`, `claude-sonnet-4` 등 상위 모델 선택 가능)
- **로컬 실행기 권장:** 대부분의 호환 API 게이트웨이는 브라우저 직접 호출(CORS `OPTIONS`)을 허용하지 않으므로, 로컬 실행기로 `http://localhost:8765`를 열어 사용하는 것이 안전합니다.
- **실시간 음성인식 브라우저 권장:** 기본으로 쓰이는 실시간 한국어 받아적기(Web Speech API)는 일반 **Google Chrome**에서 가장 안정적으로 동작합니다.
- **모델 선택 안내:** `자동` 모드는 가중치 `0.5x` 상위 모델(`gemini-3-flash` 등)을 우선 사용하고, 대본 기반 한국어 표현 품질을 우선할 때는 `claude-sonnet-4`(`1.0x`) 등을 고급 설정에서 선택할 수 있습니다. 구형 `2.5` 이하 모델은 제외됩니다.

---

## 실행하기

외부 패키지 설치가 필요 없습니다(**설치 용량 0 MB**, 실행 시간 약 1초).

### 준비물
- **런타임:** Node.js 18 이상 또는 Python 3 (둘 중 하나)
- **브라우저:** 일반 **Google Chrome** 권장 (실시간 한국어 받아적기용)
- **게이트웨이 정보:** OpenAI 호환 게이트웨이 API Base URL, OpenAI 호환 Virtual Key

### 1단계 · 저장소 폴더에서 로컬 실행기 시작
터미널을 열어 저장소 폴더(`peer-feedback`)로 이동한 뒤, PC 환경에 맞는 명령어 한 줄을 실행하세요.

- **Windows (PowerShell) · Node.js 18 이상 환경:**
  ```powershell
  cd peer-feedback
  node server.mjs
  ```
- **macOS · Linux (Python 3 또는 Node.js):**
  ```bash
  cd peer-feedback
  python3 server.py
  # 또는 node server.mjs
  ```

### 2단계 · Google Chrome에서 열고 연결 테스트하기
1. 실행기가 시작되면 기본 브라우저로 `http://localhost:8765`가 자동으로 열립니다. 다른 브라우저가 열리거나 자동으로 열리지 않으면 **일반 Google Chrome** 주소창에 `http://localhost:8765`를 직접 열어 주세요. *(일부 크로미움 파생 브라우저는 내장 음성인식 API가 제한될 수 있습니다.)*
2. 상단 **1. 게이트웨이 연결 및 테스트**에 **게이트웨이 API Base URL**과 **OpenAI 호환 Virtual Key**를 입력합니다.
   - 매번 주소를 입력하지 않으려면 `http://localhost:8765/#api=https://게이트웨이주소` 형태로 북마크해 두세요.
3. **`연결 테스트`** 버튼을 눌러 로컬 프록시, 키 권한, 텍스트 초안 생성 가능 여부를 확인합니다.

### 3단계 · 녹음, 초안 생성, 종료
1. 브라우저 마이크 권한을 허용하고 **`● 녹음 시작`**을 누릅니다. 기본으로 펼쳐진 **실시간 한국어 받아적기 · 대본** 창에서 인식되는 내용을 바로 확인하며 동료평가 대화를 진행하세요.
2. 대화가 끝나면 **`■ 평가 종료 및 초안 생성`**을 누릅니다. 생성이 완료되면 메모리와 임시 버퍼(IndexedDB)의 음성은 즉시 파기됩니다.
3. **3. 화자 역할 및 초안 다듬기**에서 포인트를 체크/추가하거나 역할을 바꾸고, 말투·분량을 조정해 초안을 복사합니다.
4. 사용을 마친 뒤 공용 PC라면 **`저장된 키·주소 삭제`**를 누르고, 실행기 터미널에서 **`Ctrl+C`**로 서버를 종료하세요.

### 자주 겪는 문제 빠른 해결
- **CORS 차단 또는 "로컬 실행기가 연결되지 않았습니다" 배너가 뜰 때:** 파일을 직접(`file://`) 열지 말고, `node server.mjs` 또는 `python3 server.py` 실행 후 `http://localhost:8765`로 접속하세요.
- **실시간 받아적기가 기록되지 않을 때:** 일반 **Google Chrome**에서 `http://localhost:8765`를 열었는지, 마이크 권한이 허용되었는지 확인하세요. 대화 메모를 직접 붙여넣어 **`이 대본만으로 초안 생성`**으로 만들 수도 있습니다.
- **8765 포트가 이미 사용 중일 때:** 실행기가 `8766`–`8775` 포트를 자동으로 찾거나, `--port 9000`처럼 원하는 포트를 지정할 수 있습니다.

### 실행기 옵션
- `--port <번호>`: 기본 포트(`8765`) 변경 (사용 중이면 `8766`–`8775` 순차 탐색)
- `--no-open`: 실행 시 브라우저 자동 열기 비활성화
- `--allow-host <호스트>`: 프록시 대상을 특정 호스트명 목록(쉼표 구분)으로 추가 제한

## 파일 구성 및 테스트

- `index.html`, `styles.css`, `src/*.js`: 외부 번들러·패키지 0개의 브라우저 네이티브 ES Modules UI
- `server.mjs`, `server.py`: Node.js / Python 3 표준 라이브러리 기반 로컬 실행기 및 CORS 프록시
- `tests/unit.test.mjs`, `tests/server.test.mjs`: Node 내장 `node:test` 기반 단위 및 서버 통합 테스트

```powershell
node --test tests/unit.test.mjs tests/server.test.mjs
```
