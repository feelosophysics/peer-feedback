개인정보 안내: 기본 제공자인 호환 게이트웨이 API 또는 Google AI Studio 무료 API를 선택해 사용할 수 있습니다. 로컬 디스크에는 파일을 저장하지 않으며(충돌 복구용 브라우저 임시 버퍼 제외), 분석 완료 즉시 서버 업로드 파일(files.delete)과 로컬 음성·대본 버퍼를 파기합니다. 음성을 외부로 전혀 보내고 싶지 않다면 '음성 외부 무전송(브라우저 음성인식 대본만 전송)' 모드를 선택하세요.
중단된 이전 평가 세션 데이터가 브라우저 임시 버퍼(IndexedDB)에서 발견되었습니다
